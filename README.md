# Explainable Multimodal Glioma Classification

An explainable multimodal deep learning framework for classifying **Glioblastoma (GBM)** and **Low-Grade Glioma (LGG)** by integrating gene expression data with MRI acquisition and clinical metadata.

## 🔬 Approach

- Gene expression dimensionality reduction using an **Autoencoder**
- **128-dimensional latent feature** representation
- Early fusion of genomic and MRI metadata features
- **MLP** for GBM/LGG classification
- **KernelSHAP** for interpretable feature attribution

## 📊 Results

- **Accuracy:** 95.20%
- **F1-Score:** 0.944
- **AUC:** 0.971

## 🛠️ Technologies

**Python | Deep Learning | Autoencoder | MLP | KernelSHAP | Explainable AI | Radiogenomics**

## 🚀 Future Work

Future improvements include integrating 3D MRI data, cross-attention mechanisms, multi-grade classification, and larger clinical datasets.
